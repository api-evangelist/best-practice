The FHIR API for Bp Premier allows Bp Partners to query Best Practice Premier databases using the HL7® FHIR® standard. FHIR doesn’t just define a data standard though — it also defines a standard for documenting FHIR products, via something called an Implementation Guide, or IG. And now, the IG for the FHIR API for Bp Premier is live in the Bp Premier knowledge base!
